# 2026 年 11 月 25 日 发布与搜索联调

- **网页骨架** 在 VS Code 启动 Flask。搜索路由和发布路由分别放入 `routes/search.py` 与 `routes/publish.py`，HTML 放在 `templates/`。用户在浏览器验证搜索表单回显和发布页入口。
- **真实图文搜索** 搜索页面接入 Chinese-CLIP。用相同测试图验收，三花猫特写和绿底卡通猫的描述分别将图 2 和图 3 排在第一。
- **发布入库** 使用 `campus_app` 连接 MySQL。上传照片后保存 JPEG、EXIF 线索和 2048 字节的图片向量。用户确认发布成功并获得物品编号 `3`。
- **搜索联调** 通过 MySQL 读取已保存的图片向量，只为本次描述生成文字向量。补齐了 `database.py` 的查询函数和 `image_search.py` 的 NumPy 导入，测试客户端验证了首页、使用测试记录的排名及上传照片读取。用户随后从浏览器确认能搜回已发布的物品。
- **选填信息已入库** 发布表单增加拾取日期和校园位置。修复了 `found_area` 因缩进落到提前返回的分支，以及旧版同名发布函数覆盖新版的问题。用模拟数据库验证了带日期地点、只传照片、无效日期和超长地点四种情况。用户随后确认实际测试完成。
- **逻辑回归前置** 搜索页增加选填的丢失日期和地点。网页和训练样本共用特征函数，计算图文相似度、日期差、楼栋与房间匹配以及缺失标记。搜索仍按余弦相似度显示前三条。
- **样本导出验收** 新增样本清单模板与导出脚本。用模拟招领记录导出 10 对样本，训练集和测试集均有正负例，并确认同一实物没有跨组。Flask 测试客户端确认选填字段和无效输入处理。现有 4 项测试通过。本机 CUDA 上使用两张网图实测，「三花猫特写」将图 2 排在图 3 前。
